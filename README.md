# Touchpoint

A personal CRM for the people worth keeping up with.

Add the people who matter, tag them (`golf`, `finance program`, `Minnesota`), and note how often
you like to see each one. Anyone you haven't caught up with in a while quietly floats to the top —
no deadlines, no "overdue," just a note of how long it's been.

## What it does

- **People** — name, tags, phone, email, a link, birthday, where you met, and free-form notes
- **Tags** — click any tag anywhere to filter; pick two or more and switch between matching *any* or *all*
- **Check-in rhythm** — a per-person interval, from weekly to yearly, or none at all
- **Been a while** — anyone past their interval surfaces at the top, sorted by longest since
- **We caught up** — log the date, what it was, and a note; that person settles down until the next stretch
- **History** — every catch-up is kept per person and can be edited
- **Backup** — export the whole thing to JSON and import it back on another machine

## Running it

It's one file. Open `index.html` in a browser, or visit the hosted version.

Data is stored in your browser's `localStorage` — nothing is sent anywhere and nothing personal
lives in this repository. Export a JSON backup now and then if you use it on more than one machine.
